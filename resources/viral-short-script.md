# Viral Short Script

Each run, find ONE real, surprising, lesser-known event and write a 45–60 second narration script for YouTube Shorts, Reels or TikTok. The script follows a tested retention structure (modeled on story-style Shorts like "Why Samurai Feared The Flying Thunder").

## Inputs (all optional)
The user may pass a topic, era, region, niche (war, science, crime, business, nature, sports, inventions, disasters, heists, survival, Philippine history...), or a target length. If none are given, pick at random and vary widely. Don't reuse a topic already done in this conversation, and avoid overused stories (Titanic, Pompeii, Great Emu War, etc.) unless asked.

## Step 1: Find the topic (real events only)
1. Brainstorm 5 candidates across different eras, regions and categories. Pick the one with the strongest paradox or twist: something that sounds impossible, backwards or ironic.
2. Verify it with web search. Confirm the core facts with at least 2 credible sources (encyclopedias, museums, academic or reputable news). If you can't verify it, drop it and pick another.
3. Note what's documented versus what's legend or dramatized. Never present invented details as fact.

Good topics have: a clear protagonist, high stakes, an object or mechanism to reveal, an escalation, and a payoff moment you can end on.

## Step 2: Write the script with this structure

| Beat | Time | Job |
|---|---|---|
| 1. Paradox hook | 0–3s | A first line that contradicts itself or sounds impossible. No intro, no "did you know". |
| 2. Stakes | 3–8s | One sentence of context with a concrete number or deadline ("You see, ..."). |
| 3. Doubt/rejection | 8–15s | Someone dismisses the hero or the idea. |
| 4. Defiant action | 15–22s | The hero acts anyway. |
| 5. Escalation ladder | 22–40s | 3–5 beats that each raise tension. Use dramatic irony: the audience suspects what the characters don't. |
| 6. Re-hook question | ~40s | Ask the viewer directly ("So, what's in there?" / "So how did it work?"). |
| 7. Mechanism reveal | 40–55s | Explain how or why in one vivid analogy. It must answer the hook's paradox. |
| 8. Cut at the peak | last 2–4s | End on the trigger moment. No aftermath, no moral, no "follow for more". |

## Writing rules
- 150–190 words for 60s (about 3 words/sec). Count them.
- Present tense, conversational, short sentences.
- Drive the story with "So," (cause and effect) and "But" (reversal) as connectors.
- Use concrete specifics: numbers, objects, times, physical actions. Every line should be picturable.
- Cut dates, full names and background unless they make the story land.
- Leave out any line that doesn't raise tension or pay something off.
- The title should promise the "why" or "how" ("Why X Feared Y", "The Man Who...", "How a ___ Beat ___").

## Output format
1. **Title** (plus 2 alternates)
2. **Hook line** on its own
3. **Script**: narration only, grouped by beat with timestamps, ready to read aloud
4. **Word count / estimated runtime**
5. **Visual & B-roll notes**: one short line per beat (shots, on-screen text, SFX/music cue for the hook, re-hook and final cut)
6. **Fact check**: 2–4 bullets saying what's verified and what's dramatized or uncertain
7. **Sources**: links used for verification
8. **3 more topic ideas** for the next video, in one line each

Keep the reply to just these sections. No preamble.
