    Story backlog

    True stories Scripty already researched. The daily run takes the top one, so the order is yours to set. Researching a few at once uses less of your plan than searching for every Short.

    Teams

    Each team is a full production line of four agents. Teams work in the same toolkit by default, each on its own Shorts, so more teams make more Shorts at once (they take turns choosing stories, renders and uploads). Every extra team uses your Claude plan faster; give it its own Claude account if you have one.

    Add a team

    Leave the repo empty to share the main team's toolkit (recommended).

    Settings

    Claude account

    Checking…

    Agents use the Claude account signed in to Claude Code on this PC. To sign in or switch, press Sign in / switch, type /login in the terminal that opens, then Check again.

    More Claude accounts

    Give a team its own Claude account (Teams → Claude account), so each line has its own plan limit. Each account signs in once in its own terminal and stays signed in.

    Toolkit

    Cloned from GitHub and updated every time the app starts. Agents save their work into it.

    Gemini API key

    Scripty uses it for voiceovers. Stored encrypted on this PC.

    Autopilot

    Agents never ask questions or wait for approval. They decide, write every decision into the Short's notes and push to GitHub. Anything outside their safe list is skipped.

    Runs at that time while the app is open (or, if the app was closed then, as soon as you open it later that day). A time you set that has already passed today starts tomorrow. Clear the time to turn it off. Once a full week of Shorts is ready or on the way (see Uploads), it skips a day.
