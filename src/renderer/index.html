    Settings

    Claude account

    Checking…

    Agents use the Claude account you signed in to with Claude Code on this PC — your Pro plan. To sign in or switch accounts, press Sign in / switch, type /login in the terminal that opens, then press Check again.

    Toolkit

    The app clones your toolkit from GitHub and pulls the latest version every time it starts. Agents save their work into this clone.

    Gemini API key (voiceovers)

    Autopilot

    On: agents never ask questions or wait for approval. They pick the story, approve their own work, write every decision into the Short's notes, and push to GitHub. Anything outside their safe list is skipped instead of asked.

    The daily run starts at that time while the app is open, or as soon as you open it later that day. Clear the time to turn daily runs off.

    Rendering

    Cutter renders on this PC's graphics card with your toolkit's render worker. Set it up once (10-20 minutes: Blender for Python, the browser renderer, Remotion, speech-to-text, base 3D assets).
